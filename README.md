# zen.source

A calm, typography‑focused layout exploring minimal design principles. This project emphasizes whitespace, balance, and quiet visual hierarchy. It was built as a design study in simplicity and intentional front‑end structure.

## Purpose
zen.source is a demonstration of how minimal UI can still feel expressive and structured. It focuses on clarity, readability, and a soft visual rhythm without relying on heavy styling or complex interactions.

Features
- Clean, minimal layout
- Typography‑driven design
- Responsive structure
- Lightweight CSS
- No external frameworks

Tech Stack
- HTML
- CSS

Live Demo

Project Goals
- Explore minimalism in UI design
- Practice layout composition using only core web technologies
- Create a quiet, distraction‑free interface
